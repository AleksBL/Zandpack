Inventory — scipy_ode_vs_zand (necessary files only; everything else is regenerated by run.sh)

  device.py         device script: graphene device with SIESTA electrodes (k-sampled),
                    TBtrans, fit, writes the MPI input arrays via tofile
  run_scipy_ode.py  the Python propagator (scipy_ode via shortlib.driver.propagate),
                    saves scipy_ode_results.npz + a scipy_ode plot
  Initial.py        run length, step, tolerances; reads <name>/Arrays/
  shared.py         dH(t,sigma) and delta(t,a) — orthogonal basis, used by all methods
  Bias.py           dH/bias/dissipator for the zand run (re-exports shared)
  Bias_NO.py        the same for nozand: dH transformed to the nonorthogonal basis
  compare.py        comparison figure (canonical + dated copy) and difference metrics
  run.sh            the pipeline: device script -> scipy_ode -> zand -> nozand -> compare
  scipy_ode_2026-10-24_13-22-44.png          Python-side current, last run
  scipy_ode_vs_zand_2026-10-24_13-28-19.png  comparison figure, last run
