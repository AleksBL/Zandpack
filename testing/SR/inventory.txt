Inventory — SR (necessary files only; everything else is regenerated by run.sh)

  make_device.py   device script: graphene sheet + STM tip, real-space
                   self-energies (Real_space_SE, parallel_E=False), TBtrans,
                   writes the pickled device
  make_fit.py      loads the device, fits the self-energies, writes the MPI
                   input arrays via tofile and the pickled fit
  check.py         the Python propagator AND the comparison: scipy_ode via
                   shortlib.driver.propagate, then figure (canonical + dated
                   copy) and difference metrics; saves scipy_ode_results.npz.
                   dH here depends on the density matrix (mean-field).
  Initial.py       run length, step, tolerances (eps = 1e-8 — keep the MPI side
                   converged, see handoff.md §3.3); reads <name>/Arrays/
  shared.py        dH(t,sigma), bias pulse delta(t,a), dissipator — orthogonal
                   basis; device is orthogonal (S = I)
  Bias.py          dH/bias/dissipator for the zand run (re-exports shared)
  Bias_NO.py       the same for nozand: dH transformed to the nonorthogonal basis
  run.sh           the pipeline: make_device -> make_fit -> zand -> nozand -> check
  SR_compare_2026-10-24_13-45-07.png          comparison figure, last run
  SR_pointwise_check_2026-10-24_13-45.log     evidence log: pointwise agreement
                   with the suite environment is 4.0e-04 (the suite's printed
                   metric is the coarse-grid interpolation effect)

  Memory: runs with a sparse, well-chosen eval grid by default (ZP_TLIST logic
  in check.py); ZP_NEVAL restores a uniform grid. In the driver's HEAVY set
  (runs alone). See handoff.md §5 for the sparse-grid conventions.

  (Run through: ./run_zandpack_tests from the TestRUN root, or sh run.sh here.)
