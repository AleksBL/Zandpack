Inventory — scipy_vs_ARK4_Zand (necessary files only; everything else is regenerated by run.sh)

  make_device.py    device script: three-lead SIESTA device (k-sampled TBtrans),
                    electrode TSHS handling, writes the pickled device
  make_fit.py       loads the device, fits the self-energies, writes the MPI
                    input arrays via tofile and the pickled fit
  scipyode.py       the Python propagator (scipy_ode via shortlib.driver.propagate),
                    saves ScipyODE.npz
  Initial.py        run length, step, tolerances; reads <name>/Arrays/
  Initial1.py       original run-length files kept from the example (not used by
  Initial2.py       the current pipeline)
  shared.py         dH(t,sigma) and delta(t,a) — orthogonal basis, used by all methods
  Bias.py           dH/bias/dissipator for the zand run (re-exports shared)
  Bias_NO.py        the same for nozand: dH transformed to the nonorthogonal basis
  Compare.py        comparison figure (canonical + dated copy) and difference metrics
  run.sh            the pipeline: make_device -> make_fit -> scipyode -> zand
                    -> nozand -> Compare
  run_steady.sh     separate steady-state pipeline (device -> SCF + psinought ->
                    propagators), run via the driver's --steady mode
  get_steady_state.sh   the SCF + psinought step that run_steady.sh calls
  ZandScript.sh     legacy runner from the original example
  scipy_ode_2026-10-24_13-03-28.png          Python-side current, last run
  scipy_vs_ARK4_Zand_2026-10-24_13-03-47.png comparison figure, last run

  k-point-sampled test: make_device.py uses read_data(D_lead_ortho=False) by
  default; ZP_DLO=1 runs the experiment with True (see handoff.md §5).
