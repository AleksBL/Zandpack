Inventory — ThesisZGNR (necessary files only; everything else is regenerated by run.sh)

  device.py         device script: 3-ZGNR from SIESTA (SZ basis, kp = [30,1,1]
                    leads), TranSIESTA + TBtrans, pz-only orbitals (69), 25-
                    Lorentzian fit per lead, writes the MPI input arrays via
                    tofile. Prints a WARNING about negative fitted-Gamma
                    eigenvalues — see README.md
  run_scipy_ode.py  the Python propagator (scipy_ode via shortlib.driver.propagate,
                    ZP_CHUNK=10 piecewise by default), saves scipy_ode_results.npz
  Initial.py        run length, step, tolerances (eps = 1e-8); reads <name>/Arrays/
  shared.py         dH(t,sigma) with a mean-field term on two mid-ribbon sites
                    (Rep = 2) and the box-pulse bias — orthogonal basis; numba-
                    compatible (@njit, drive precomputed as V*M)
  Bias.py           dH/bias/dissipator for the zand run (re-exports shared)
  Bias_NO.py        the same for nozand — real SIESTA device (S != I) AND
                    sigma-dependent dH, so BOTH Lowdin transforms are needed
  compare.py        comparison figure (canonical + dated copy) and difference metrics
  run.sh            the pipeline: device -> scipy_ode -> zand -> nozand -> compare
  README.md         what the test is, the non-PSD fit warning, the settings that matter
  ThesisZGNR_run_2026-10-24_15-45.log           full pipeline log of the first run
  scipy_ode_2026-10-24_15-43-05.png             Python-side current, first run
  ThesisZGNR_compare_2026-10-24_15-43-45.png    comparison figure, first run
  ThesisZGNR_compare_2026-10-24_15-56-30.png    comparison figure (re-run of compare.py)

  Adapted from examples/ThesisExample (5a/5b/5d); the steady-state preparation
  (TDeq_1.sh: ts-contour -> modify_occupations -> SCF -> psinought) is NOT part
  of the default run.

  (Run through: ./run_zandpack_tests from the TestRUN root, or sh run.sh here.)
