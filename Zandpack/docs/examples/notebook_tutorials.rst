Notebook tutorials
==================

The up-to-date, step-by-step tutorials live in
``Zandpack/examples/nb_tutorial_updated/Tight-binding``. Each directory contains
a notebook and the ``Initial.py`` / ``Bias.py`` files needed to drive a
calculation of the corresponding system.

* ``T1_Rabi/Rabi Oscillations.ipynb`` -- Rabi oscillations in a two-level system.
* ``T2_TB_Chain/Chain.ipynb`` -- transport through a tight-binding chain.
* ``T3_Graphene/Graphene.ipynb`` -- a graphene junction.
* ``T4_N_elec/Four-electrode Setup.ipynb`` -- a four-electrode device.
* ``T5_IsolatedTip/IsolatedTip.ipynb`` -- an isolated tip.
* ``T6_HartreeFock/HartreeFock.ipynb`` -- Hartree-Fock (density-dependent)
  Hamiltonian.
* ``T7_Nanotube/Nanotube.ipynb`` -- a carbon nanotube.

*Location:* ``Zandpack/examples/nb_tutorial_updated``

An older set of tutorials is kept in ``Zandpack/examples/nb_tutorial_old`` for
reference.

.. note::

   These notebooks are referenced rather than rendered here, because the
   documentation would otherwise keep a second, drifting copy of each notebook.
   Open them directly from the examples folder, or see the rendered notebooks
   below.
