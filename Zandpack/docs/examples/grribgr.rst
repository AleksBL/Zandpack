GrRibGr
=======

Tight-binding example without any density-matrix dependence in the Hamiltonian.
The system is a graphene nanoribbon bridge between two semi-infinite graphene
sheets. For both sides a semi-infinite surrounding self-energy is calculated
using ``Real_space_SI`` from ``siesta_python``.
