Reproduce_and_checks
====================

``Zandpack/examples/Reproduce_and_checks`` contains scripts that were used to
verify the various steps of the code during development, grouped by reference or
method:

* ``Croy2009``, ``PopescuCroy2016``, ``Honeychurch2018`` -- reproduce published
  results.
* ``scipy_ode_vs_AdaptiveRK4``, ``scipy_ode_vs_Adaptive_PBC``,
  ``scipy_vs_ARK4_Zand`` -- integrator cross-checks.
* ``Rib``, ``SR`` -- ribbon and self-energy checks.
* ``restart_check`` -- restart behaviour.

*Location:* ``Zandpack/examples/Reproduce_and_checks``
