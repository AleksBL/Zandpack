Please note that these tools in this folder have been "vibe-coded" using LLM tools (GLM 5.3), but they have been quite thoroughly checked that they actually work as intended and improves upon the previous (human-written) code. In the case of the FittedSelfEnergy.py, this module reproces the results of the non-AI version to numerical precision, while the FittingRoutine module improves on the fitting of the electrode Gammas / Level-width functions quite substatially. In the case of the fitting routine, verifying that the result is valid is quite easy (See the implementation file), as the functional form is fixed, and the transmission function and DOS can be used to gauge the quality of whatever comes out of the LLM produced code.
